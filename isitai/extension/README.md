# IsItAI Chrome/Firefox extension

Load unpacked:
1. Chrome → `chrome://extensions` → enable Developer mode → "Load unpacked" → select this folder.
2. Firefox → `about:debugging` → "Load Temporary Add-on" → pick `manifest.json` (MV3 is supported).

Right-click any image on the web → **Detect with IsItAI** → opens the full forensic
report (URL mode) with heatmap overlay, signals and shareable evidence link.
